# Simplex Noise Luau Implementation (2D, 3D)
This repository simply covers the implementation of simplex noise, created by Ken Perlin, in Luau. The approach provides a direct return of the noise functions. There is no API, for performance reasons. The motivation for developing the algorithm was simply because I needed and wanted to.

The article by Stefan Gustavson (*Simplex noise demystified*) was followed, given that it covers more ground. You can view it here: [Article](https://cgvr.cs.uni-bremen.de/teaching/cg_literatur/simplexnoise.pdf)
